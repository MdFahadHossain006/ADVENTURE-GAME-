An immersive open-world adventure game where players can explore forests, oceans, villages, and modern cities while experiencing the journey of **FAHAD**, a fearless explorer who loves adventure and discovery.

Inspired by survival, exploration, and freedom — this project creates a beautiful world where players can travel, hunt animals, explore hidden locations, and enjoy realistic environments directly in the browser.

---

## ✨ Features

- 🌲 Explore massive forests
- 🌊 Travel across seas and beaches
- 🏙️ Visit cities and villages
- 🧍 Play as **FAHAD**
- 🐾 Hunt and interact with animals
- 🎮 Open-world gameplay experience
- 🌅 Beautiful environment design
- ⚡ Lightweight browser-based game
- 💻 Built using pure web technologies

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

---

## 🎯 Game Concept

The game focuses on freedom and adventure.

You play as **FAHAD**, an adventurer exploring a huge world full of nature, mystery, wildlife, and beautiful landscapes. Players can walk through forests, swim near oceans, discover villages, and survive in the wilderness.

The goal is not only survival — it’s about exploration, discovery, and enjoying the beauty of the world.
